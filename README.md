# УП.01.01. Сеть банковских отделений

Учебная практика УП.01.01 по модулю ПМ.01 «Разработка модулей программного обеспечения для компьютерных систем», вариант 19.

Тема курсового проекта: «Проектирование и разработка базы данных для системы управления сетью банковских отделений и клиентами».

Выполнил: Прокофьев М. А., группа 4ИСИП-123.

WPF-приложение для вымышленного банка АО «Прогресс-Банк»: учёт клиентов, отделений и счетов. Клиент банка может просматривать список пользователей, администратор редактирует таблицы, строит диаграммы и выгружает отчёты в Word, PDF и Excel.

## Технологии

- C#, WPF (.NET Framework 4.8)
- Microsoft SQL Server, Entity Framework 6 (Database First)
- System.Windows.Forms.DataVisualization (диаграммы)
- Microsoft.Office.Interop.Word и Microsoft.Office.Interop.Excel (выгрузка отчётов)

## База данных

Три таблицы:

- **Users**: учётные записи. Роль `User` означает клиента банка, `Admin` означает администратора. Пароли хранятся в виде SHA1-хэша.
- **Branch**: отделения банка.
- **Account**: счета клиентов в отделениях.

Удаление пользователя или отделения каскадно удаляет связанные счета.

## Как запустить

1. Выполнить скрипт `db/schema.sql` в SQL Server Management Studio. Скрипт создаёт базу `DB_Prokofev_Bank` и заполняет её тестовыми данными. Скрипт рассчитан на сервер, где этой базы ещё нет. Если она уже есть, сначала удалить её.
2. Проверить строку подключения `Entities` в `App.config`. По умолчанию используется сервер `(localdb)\MSSQLLocalDB`. Если база создана на другом сервере, заменить значение `data source`.
3. Открыть `UP01_Prokofev_Bank.slnx` в Visual Studio и запустить приложение (F5). Пакет EntityFramework восстановится автоматически.

Для выгрузки отчётов нужен установленный Microsoft Office. Файлы `Accounts.docx`, `Accounts.pdf` и `Accounts.xlsx` сохраняются в папку «Документы».
